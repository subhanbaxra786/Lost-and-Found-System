# Lost and Found Management System

A Java-based Object-Oriented Programming project designed to manage lost and found items within a university or institutional environment.

## Overview

The Lost and Found Management System provides a centralized platform for users to report lost items, register found items, search available records, and submit claims for recovered belongings.

## Features

- User registration and login
- Lost item reporting
- Found item reporting
- Item searching
- Claim submission and verification
- Admin management
- File-based data persistence (CSV)

### Completed
- User management
- Student/Admin roles
- Lost/found item models
- CSV persistence
- Basic application controller
